# Problem-Solving-With-ME

This repository is dedicated to solving **Data Structures & Algorithms (DSA)** and **Competitive Programming (CP)** problems from multiple platforms.

The goal is to:
- Keep useful problems in one place so others do not have to search for them repeatedly.
- Share my thought process and approaches for each problem.
- Help beginners build critical thinking skills through explained solutions.

## Platforms Covered

- **LeetCode** (problems and contests)
- **Codeforces** (problems and contests)
- **GeeksforGeeks** (problems and contests/challenges)
- **CodeChef** (problems and contests)

## Language

All solutions in this repository will be written in **C++**.

## Notes

New problem solutions and contest solutions will be added here regularly.
